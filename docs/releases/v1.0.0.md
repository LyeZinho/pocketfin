# PocketFin 1.0.0

First stable release of **PocketFin** — a fast, offline-first expense tracker
built with Flutter.

## Highlights

- **Offline by default.** Every transaction is stored in a local SQLite
  database; no account and no server required.
- **Fast entry.** Custom numeric keypad, expense/income toggle, categories and
  an optional note.
- **Clear overview.** Balance, monthly budget and today's activity on Home.
- **Real statistics.** Week/month/year views with a category donut, daily spend
  chart and a comparison tip.
- **A coach, not a dashboard.** Insights built from your own history: your most
  expensive weekday, savings rate and recurring subscriptions.
- **Backups you own.** Export to `.xlsx` and share the file anywhere. Import a
  PocketFin backup later; existing entries are preserved and exact duplicates
  are skipped.
- **Dark visual system** with the lime, coral and purple palette from the
  product mockups.

## Install

1. Download `pocketfin-1.0.0.apk` below.
2. On Android, allow installation from this source when prompted.
3. Open PocketFin and start adding entries.

Requires Android 7.0 (API 24) or newer.

## Notes

- This APK is signed with Flutter's debug keystore. It installs and runs, but
  it is not the artifact to upload to the Play Store. A production keystore is
  required for store distribution and update continuity.
- Import/export supports `.xlsx`; legacy `.xls` is not implemented.
- iOS was not compiled for this release.
